## Clicker Arena — Telegram Mini App

## Важно: сначала отзови старый токен
В исходном загруженном `bot.py` токен Telegram-бота записан прямо в коде. Считай его скомпрометированным: открой **@BotFather → /mybots → выбери бота → API Token → Revoke**. Затем используй только новый токен в `.env`. Не публикуй `.env` и не отправляй токен в чат.

## Что реализовано
- Telegram Mini App с адаптивным интерфейсом, анимированной кнопкой, всплывающими монетами, прогрессом XP и рейтингом.
- Начисление валюты на сервере, а не в браузере.
- Проверка подписи `Telegram.WebApp.initData`.
- Общая база игроков SQLite и таблица лидеров.
- Прибыль за клик: уровни 1–9 = 10 ₽; 10–19 = 100 ₽; 20+ = 500 ₽.
- Сложность уровня растёт квадратично: уровень L требует `100 × L²` XP; один клик даёт 1 XP.
- «Онлайн» сейчас показывает количество зарегистрированных игроков. Для настоящего количества одновременно активных пользователей нужно добавить heartbeat/presence и TTL.

## Запуск
1. Установи Python 3.11+.
2. `pip install -r requirements.txt`
3. Скопируй `.env.example` в `.env`, вставь НОВЫЙ токен и HTTPS-адрес сайта:
   `BOT_TOKEN=...`
   `WEBAPP_URL=https://your-public-domain.example`
4. Размести папку `webapp` и `app.py` на публичном сервере с HTTPS. Telegram Mini Apps требуют HTTPS.
5. Запусти API: `uvicorn app:app --host 0.0.0.0 --port 8000`
6. Запусти бота в другом процессе: `python bot.py`
7. В @BotFather настрой домен Mini App для бота, если Telegram попросит.

Для локальной проверки можно использовать HTTPS-туннель (например, Cloudflare Tunnel) к порту 8000. Не открывай API без HTTPS в публичной сети.

## Важные замечания перед релизом
- Добавь rate limiting на `/api/click`, мониторинг ошибок, резервное копирование SQLite и миграции.
- «Онлайн» — зарегистрированные игроки, а не live-сессии; это явно обозначено в README.
- Не используй виртуальные ₽ как реальные деньги без отдельной юридической и платёжной проработки.
- Этот комплект — рабочая стартовая основа Mini App, а не развернутый публичный сервис. Перед большим онлайном перенеси БД на PostgreSQL и добавь защиту от автоматизированных кликов.
